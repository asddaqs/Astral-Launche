# Astral Launcher · 星穹启动器

Minecraft Java 启动器的公开版本与更新发布仓库。

## 下载

请在 [Releases](https://github.com/asddaqs/Astral-Launche/releases) 获取稳定版本。首次使用需要含 browser-runtime 的完整便携包；已有启动器可通过设置中的「启动器更新」更新程序。

## 更新源

`https://github.com/asddaqs/Astral-Launche`

更新程序会验证 SHA256、文件大小和版本，并在正常退出后安装。账号、设置、实例与存档保留。

## 1.1.0

- 下载失败后的断点续传，主动取消仍清理。
- 世界存档信息、导入新世界、导出单个世界与备份恢复。
- GitHub Releases 更新检查与校验安装。

请勿在公开仓库上传 launcher.json、登录令牌、个人日志、实例或存档。
