# 常见问题

### 下载哪个文件？

1.2.2 起首次使用及更新都下载约 8 MiB 的 `AstralLauncher.exe`。缺少 WebView2 时启动器会联网自动准备。GitHub 的 Source code 不是启动器安装包。

### 只有一个 EXE，界面打不开？

确认使用 1.2.2 或更新版本，放在可写位置。缺少运行环境时首次准备需要联网并预留足够磁盘空间；可以取消下载，已开始的微软安装会等待其完成。若失败，请检查网络或从微软 WebView2 官网手动安装 Evergreen Runtime，然后重新运行。不要把旧版小 EXE 与新版自动准备功能混淆。

### 下载失败能续传吗？

重新下载相同内容时，会在可校验、服务器支持的情况下使用已下载片段。主动取消会删除相应未完成内容；不支持可靠续传时重新下载。

### 为什么生成 Astral 和 .minecraft 文件夹？

它们分别保存启动器数据和游戏数据，属于正常工作目录。不要随意删除。公开反馈时不要上传整个文件夹。

### 切换加载器后模组不能运行？

不同加载器的模组通常不通用。切换操作保留模组与存档，请安装匹配版本并查看缺失前置提示。

### 联机失败或看不到皮肤？

确认双方版本、加载器与模组兼容，检查 IPv6 和网络环境。公共 STUN 无法保证所有网络打洞。原版客户端不一定识别第三方皮肤，启动器不能保证绕过游戏和服务器的皮肤规则。

### AI 能直接免费使用吗？

需要自行配置在线接口、模型和密钥，费用及数据处理由所选服务决定。请核对日志预览与操作建议，不要发送密码或令牌。

### 如何报告崩溃？

先查看本地崩溃诊断，再到 Issues 提供版本、复现步骤、截图及脱敏错误片段。不要附完整账号配置或私人数据。
