# 使用指南

## 安装与升级

从 1.2.2 起，首次使用只需下载约 8 MiB 的 `AstralLauncher.exe`，放入可写文件夹运行。优先复用系统 WebView2；没有时，尝试旧版完整外置内核，两者均不可用则从微软官方下载 WebView2 引导安装程序，校验有效微软签名后以当前用户安装。首次准备需联网，已有运行环境时无需重复下载。

升级前正常退出启动器，替换 EXE（本机原名为 `Astral Launcher.exe` 时保持原名）。系统 WebView2 使用微软 Evergreen 更新机制。旧内核作为备用保留，不自动删除。不要覆盖或删除其他用户数据。也可在设置中配置本仓库并使用内置更新。若自动准备失败，可从 https://developer.microsoft.com/microsoft-edge/webview2/ 安装 Evergreen Runtime 后重新启动。

## 账号与游戏

添加微软、离线或第三方账号后，在「下载」选择版本和兼容加载器。微软登录使用自己的合法账号；离线账号的使用范围取决于游戏及服务器要求。主页选择实例后启动，星球旋转不会自动改变启动目标。

## 模组与整合包

社区资源可使用聚合来源或单选 Modrinth / CurseForge。安装前核对游戏版本、加载器与前置依赖。将支持的 ZIP / MRPACK 整合包拖入启动器可导入。

实例管理中使用「更多」打开模组或存档目录、管理存档、更换加载器或导出。导出为 `.mrpack`，不包含账号、私人存档和日志；世界需单独导出。更换加载器保留原模组，不会将其转换为另一加载器格式。

## 世界与备份

默认启动前自动备份世界，各实例保留最近 5 份；可在设置调整。恢复前先退出游戏，启动器会保护当前存档再恢复快照。大世界备份会延长启动等待。日常备份存放于 `Astral`，请定期复制到其他磁盘。

## 皮肤与 AI

皮肤页面支持 3D 预览、PNG 导入和删除本地皮肤。删除本地皮肤不等于删除账号服务端皮肤。在线换肤依赖账号服务支持。

AI 需在设置中填写自定义 HTTPS 接口、模型与密钥。在统一聊天窗口描述需求；发送日志前查看脱敏内容，修复或安装前核对操作清单。翻译生成独立资源包，不改写原模组 JAR。

## 联机

双方使用兼容游戏环境，房主先开放本地房间。可用 IPv6 时分享地址，否则按页面交换 WebRTC 邀请和回执。公共 STUN 不提供流量中继，部分 NAT 环境无法打洞。详见 [P2P 联机说明](P2P联机说明.md)。

## 文件位置

默认 `Astral/` 保存启动器数据，`.minecraft/` 保存游戏数据。移动便携版时一并复制；外部绝对路径指向的实例需另行迁移。更改安装目录只影响新实例，不自动搬迁旧实例。
