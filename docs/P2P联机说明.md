# 点对点联机使用说明

双方使用同版本游戏和一致的模组。此功能用于 Minecraft Java 版 TCP 游戏连接。

房主：启动世界 → 游戏内“对局域网开放” → 启动器“联机”页确认游戏端口 → “开启本地 MC 房间”。检测到公网 IPv6 时会显示 IPv6 地址，同时准备 WebRTC 邀请。复制邀请码或分享二维码。

好友：在“加入房间”粘贴邀请码，或导入二维码图片。程序优先尝试 IPv6；失败则生成 WebRTC 回执码。将回执码发回房主，由房主导入完成握手。连接成功后可“启动并加入”，游戏已运行时复制本地连接地址到游戏的“直接连接”。

没有信令服务器，因此 WebRTC 需要邀请码和回执码来回交换。编码包含完整压缩 SDP，长度取决于网络候选，并非可由服务器查询的短号。二维码容量不够时请复制完整文字。邀请 30 分钟过期，每位好友单独使用一份邀请。

Google 公共 STUN（stun:stun.l.google.com:19302）只用于发现网络地址，不承担游戏流量中继。连接失败可能是 NAT、防火墙或 STUN 不可达；可启用公网 IPv6，或自行部署 VPS/TURN 中继。当前版本不包含托管中继服务，也不保证所有网络均能打洞。

联机期间保持启动器运行。切换页面不影响连接；关闭房间或退出启动器会断开连接。房主关闭本地世界也会自动关闭房间。无需安装虚拟网卡或额外驱动。
