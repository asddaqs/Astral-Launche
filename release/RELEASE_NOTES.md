## 首次使用只需一个 EXE

下载下方 **AstralLauncher.exe**（约 8 MB），放入可写文件夹后运行。优先使用电脑已有的 WebView2；缺少时，从微软官方下载、验证签名后安装。无需另外下载完整便携包，首次准备运行环境可能需要联网。

## 本次更新

- 轻量程序分发，优先复用系统 WebView2，兼容旧版完整便携内核作为备用。

GitHub 自动附加的 Source code 不是启动器安装包。

升级前正常退出启动器；已有文件名为 `Astral Launcher.exe` 时保持原名替换。保留 `Astral`、`.minecraft` 和外部实例目录。系统浏览器缓存与旧版固定内核缓存隔离，账号、实例和存档保持原有位置。

支持 Windows 10 / 11 x64。官方安装程序下载与签名校验、系统内核启动及太阳 / 地球渲染已测试；本机已有 WebView2，缺失环境的安装分支通过流程测试，未通过卸载系统组件来测试全新系统。

使用指南与常见问题见仓库首页；反馈时请隐藏账号、令牌和 API 密钥。
