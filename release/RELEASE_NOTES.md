# Astral Launcher 1.4.1

本次保留1.4.0全部功能，重点优化实例管理、启动资源和3D皮肤预览。首次使用或升级下载 **AstralLauncher.exe** 即可，无需完整便携包。

## 优化内容

- **实例管理**：刷新列表时复用已有卡片，删除或替换实例后释放旧控件，避免反复切换页面导致界面缓存持续累积；当前实例置顶和图标更换保持正常。
- **启动资源**：相同的浏览器界面资源不再重复写入；升级、文件缺失或损坏时仍会重新准备，减少启动磁盘写入。
- **图标缓存**：内置物品和纹饰图标复用编码，减少后台刷新时的临时分配。
- **3D皮肤与盔甲**：批量读取纹理像素，复用最多32项盔甲合成纹理；重复选择同一套装备时保留预览，旋转、缩放和实际装备变化仍正常刷新。
- 保留陶瓦像素画与投影导出、盔甲分部位搭配、24种实例物品图标、MP3背景音乐及现有联机、资源下载和管理功能。

## 验证与使用

已验证反复刷新实例列表时控件登记数量保持稳定；8组优化前后皮肤渲染逐像素一致，普通、透明及索引色皮肤通过检查。皮肤、像素画、图标、音乐、实例管理及单EXE启动回归通过；第二次启动复用13个界面资源文件，没有重复写入。

升级前正常关闭启动器，仅替换EXE，保留 `Astral`、`.minecraft` 和外部实例文件夹。本机原文件名为 `Astral Launcher.exe` 时请保留原名。
