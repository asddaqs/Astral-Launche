# Astral Launcher 1.4.0

下载 **AstralLauncher.exe** 即可首次使用或升级，无需完整便携包。优先使用系统 WebView2；缺失时自动从微软准备运行环境。

## 本次更新

- **图片转方块画**：羊毛、混凝土与陶瓦共49色，可单选材料，支持透明像素、抖动配色、材料清单、PNG预览，以及 Litematic / Sponge 投影导出。
- **皮肤与盔甲**：3D皮肤预览；头盔、胸甲、护腿和靴子可独立穿脱搭配，支持18种纹饰模板与10种材料，使用原版物品图标。
- **实例图标**：24种原版物品图片，点击实例图标或进入设置即可更换，保存后记住选择。
- **背景音乐**：导入MP3，支持音量、暂停、循环和启动时播放，切换页面持续播放。
- **实用工具**：坐标与维度换算、区块和距离计算、附魔搭配及互斥检查、版本适配命令生成。
- **联机与管理**：EasyTier房间号与二维码、公共/自定义节点、服务器收藏；模组批量更新、截图相册、磁盘空间管理、更换加载器和整合包导出。
- 保留聚合Modrinth/CurseForge下载、断点续传、存档备份恢复、AI聊天助手和纯黑星空界面。

## 升级与文件

升级前正常退出启动器，仅替换EXE，保留 `Astral`、`.minecraft` 和外部实例目录。若本机文件名为 `Astral Launcher.exe`，替换时保留原名。

| 附件 | 用途 |
| --- | --- |
| AstralLauncher.exe | 首次使用及升级的主程序 |
| AstralLauncher.exe.sha256 | SHA256完整性校验 |
| update.json | 启动器自动更新清单 |

推荐Windows 10/11 x64。首次准备WebView2、Java、游戏及联机组件需要联网。EasyTier组网助手创建虚拟网卡需要管理员授权，免费社区节点速度与可用性取决于提供者。

已通过方块画投影格式往返、图标保存取消、盔甲独立部位、真实浏览器MP3播放、大小窗口及单EXE启动检查。投影尚未在Minecraft客户端实测导入；EasyTier管理员/TUN创建和跨设备进服仍需实际环境验证。
