# Astral Launcher 1.5.0

本次加入五项实例与联机管理功能，并包含最新内存占用和界面流畅度优化。首次使用及升级均下载 **AstralLauncher.exe**。

## 新增功能

- 模组管理。读取 Fabric、Quilt、Forge 和 NeoForge 模组信息，查看依赖，预览关联影响后启用或禁用，支持搜索和本地 JAR 导入。
- 实例变更记录。记录受管理文件和实例设置的变化，按内容去重，默认保留最近 10 条。恢复前创建保护记录，并检查文件完整性和并发修改。
- 联机环境同步。比较双方游戏及模组环境，按可靠原始来源下载并校验，在独立实例中安装。无法识别的文件列入手动处理清单。
- 资源包与光影管理。导入 ZIP，查看封面、格式提示，调整资源包顺序及启用状态，选择光影。缺少支持时可搜索匹配版本的 Iris。
- 启动性能报告。记录进程创建、首个游戏窗口、可识别的主菜单信号和 Java 工作集峰值，退出游戏后保存，保留最近 10 次并关联变更记录。

入口位于实例管理的“更多 → 管理工具”。联机环境同步位于联机页面，启动性能报告也可从日志页面打开。

## 性能与修复

- 皮肤缩略图缓存逐张淘汰，优先保留当前角色和最近查看的图片，减少滚动时重复生成。
- 离开皮肤页后释放可重建的预览缓冲，返回时恢复皮肤、装备和视角。
- 配方预览复用物品图片，选择槽位时减少重复编码和磁盘写入；离开页面或关闭控件后清理过期界面图片。
- 延续实例卡片复用、静态界面资源复用和后台刷新节流。
- 修复 EasyTier 官方组件中 Packet.dll 未提取造成的启动失败，使用固定官方版本和文件校验。

## 验证范围

本轮内存与界面优化通过 217 项检查，涵盖缓存、皮肤、图片转方块画、图标、音乐、后台下载与联机浏览器保活，以及真实单文件启动。受控测试中，100 次配方预览更新使用的图片文件由 101 张降至 1 张。整体长期内存降幅仍需进一步测量。

真实跨设备 TUN 进服，以及资源包和光影在 Minecraft 内的实际显示仍待验证。部分游戏版本没有可靠的主菜单日志信号，对应报告字段会留空。

## 下载与升级

| 附件 | 用途 |
| --- | --- |
| AstralLauncher.exe | 首次使用与升级主程序 |
| AstralLauncher.exe.sha256 | SHA256 完整性校验 |
| update.json | 自动更新清单 |

推荐 Windows 10 / 11 x64。优先复用系统 WebView2，缺少时首次运行联网准备。升级前正常关闭启动器，替换主程序，并保留 Astral、.minecraft 及外部实例文件夹。
